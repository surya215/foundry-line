Foundry Line is a three.js tactical FPS: 5v5 bomb plant/defuse on the Foundry-9 map, four weapons (P9, Kestrel-9, VK-7, Longshot .50), two grenades (Surge HE, Veil smoke), a buy economy, bot teammates and enemies that follow routes, hold sites and react to sight and sound, synthesized WebAudio, and a full HUD — all running offline in the browser.

## Run it

```sh
node --experimental-strip-types serve.ts
# open http://localhost:8080
```
